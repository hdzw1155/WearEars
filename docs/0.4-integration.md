# 0.4 功能合入说明

本地工作区以 0.3.5 的 `552fcbf` 为外观基准，合入连接、磁贴及设置功能。当前版本为 0.4.0（versionCode 13），未提交、未推送、未安装到设备。

## 界面与设置

主页只有一个“设置”入口，打开原有 SettingsActivity。沿用 0.3.5 的卡片背景、字号、间距和选择态。保留极简、液位、经典三套界面与三套磁贴；没有新增页面或实验布局。

同一设置页包含界面风格、磁贴风格（含跟随界面）、语言（含跟随系统）、已配对耳机选择、音量条显示。音量偏好与原开发者开关共用，原有空间音频、DeepX 和提示确认保留。

主页 XML 只删除未启用的 Suprem 覆盖层；SupremView、SupremTicksView 及相关设置入口、字符串已删除。AppScrollView、ArcIndicatorView、NoiseSegmentedView、VolumeBarView、三套电量视图与磁贴画法均沿用 0.3.5。

## 连接与磁贴

- HeadsetController 供主页与磁贴共用，协议写入走工作线程，回调带连接代数并集中到主线程。切换设备不复用其他设备的数据。
- 回前台查询状态；前台连接期间每 60 秒查询电量及降噪。失败按 3、6、12 秒间隔最多重试 3 次，轮询不发起额外重连。
- 页面不再需要连接、且磁贴没有待完成操作时关闭通道。仅磁贴渲染不会启动蓝牙连接；点击电量区域会短暂连接查询。
- 磁贴仍立即显示点击目标。已确认档位与临时目标分开保存；目标有 12 秒期限，失败后显示最近确认结果。连续点击以最新目标为准。
- 资源按布局请求中的版本还原对应数据，图片缓存包含语言；模式变化复用电量图片。数据变化合并推送，进入磁贴时读取快照，不设置周期刷新。
- UI 合入阶段补了连接取消与迟到回调守卫；后续协议修正和 Sony / Technics 接入见 [协议验证记录](protocol-validation.md)。

## 验证与后续接手

已用原 `scripts/build.bat` 完成资源编译、Java 8 编译、D8、对齐及签名，输出 `wearears-debug.apk`。沿用现有 JDK、SDK 和依赖，无 Gradle，无 Lambda / 方法引用。

未安装、未做真机交互验证、未测续航。构建通过不能代替 Galaxy Watch7 的蓝牙和磁贴宿主验证；仍需在设备上确认设置返回即时生效、三套旧风格、连续切档、磁贴刷新和进入/退出时的连接状态。

后续改动继续以“0.3.5 外观 + 新旧功能保留 + 单一设置入口”为边界，不自行换布局或配色。
